# API Key 添加教程

## 你会接触到的 2 类 Key

### 1. SiliconFlow API Key

用途：

- 给默认智能通道提供你自己的 SiliconFlow 配额
- 不填也能用，但会走我们服务端内置的默认 Key

适合：

- 你希望使用自己的额度
- 你希望和默认服务端 Key 隔离

### 2. MiMo API Key

用途：

- 作为备用 AI 通道
- 也可以在设置页里切换成主通道

适合：

- 你已经有 MiMo 配额
- 你想把分析能力切到 MiMo

## 添加方式

进入小程序 `本地设置`：

1. 在 `SiliconFlow Key` 输入框填你的 SiliconFlow Key
2. 在 `MiMo Key` 输入框填你的 MiMo Key
3. 点击 `保存设置`
4. 需要时再主动点校验按钮

## 安全说明

1. Key 只保存在当前设备本地
2. 我们不会把你的消息、图片、文件上传到云端数据库
3. 只有在你主动使用 AI 分析时，本次必要内容才会发送到对应 AI 服务
4. 前端本地保存不等于绝对安全，所以仍建议只使用你自己的限额 Key
